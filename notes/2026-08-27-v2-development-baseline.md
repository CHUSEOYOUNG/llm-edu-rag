# 개발용 평가셋 v2 고정 — 2026-08-27

## q008 승인 반영

사용자가 승인한 2028년 시행 범위를 다음처럼 독립적으로 이해할 수 있는 질문으로 반영했다.

> 코퍼스에 포함된 국가교육위원회 고시 제2026-1호에서, 2028년 3월 1일부터 초등학교 1·2학년에 적용하도록 정한 교과는 무엇인가요?

원 질문은 `original_question`에, 승인된 변경 전후 문장은 manifest에 저장했다.
v1 질문 파일과 reference answer, 기존 gold_chunks는 변경하지 않았다.
보류 사유를 해제하고 q008을 포함한 answerable 11개를 개발 평가 대상으로 확정했다.

## q008의 근거 규약

질문이 요구하는 답은 교과 목록이다. 이를 하나의 필수 그룹으로 지정했다.

- 총론 `s019::1::0`: 1·2학년 교과 목록 문장과 개정일.
- 총론 `s020::2::0`: 같은 목록이 있는 표 1의 1~2학년 열. 이전 PDF 시각 검토로 해당 열을 확인했으나 추출 표의 구조 손상은 그대로다.

시행일은 이전에 확인한 PDF 7쪽 부칙을 annotation의 적용 범위 조건으로 기록한다.
시행일 자체를 답변에서 새로 찾아 말하라고 묻는 질문으로 평가하지는 않는다.
따라서 교과 목록 근거 확보 점수와 시행일 문장의 검색 가능성은 별개다.
이 규약은 교과 목록 검색 성공을 시행일 검증 성공으로 과장하지 않기 위한 것이다.

시행일 문구는 현재 s003::다::0/1의 path에 있고 body에는 없다.
본문 색인만으로 해당 날짜 문구를 직접 검색할 수 없다는 구조적 문제는 해결하지 않았다.
고시 내용에 대한 로컬 코퍼스 평가이며 외부의 후속 개정 여부를 확인한 정책 안내는 아니다.

## 재검색 결과

모델 BAAI/bge-m3, body-only 문서 임베딩, 원래 검색 설정을 유지했다.
변경된 q008 질문을 새로 임베딩하여 검색했다.

| q008 | 원 질문 + 새 근거 | 승인된 질문 + 동일 근거 |
|---|---:|---:|
| Hit@5 | 1.000 | 0.000 |
| Coverage@5 | 1.000 | 0.000 |
| MRR@20 | 1.000 | 0.000 |

문장 근거와 표 근거가 모두 top20 밖으로 밀렸다.
상위에는 개정 고시, 시행일·적용례 안내 등이 검색됐다.
1위에는 일부 교과 관련 표현이 있지만 전체 교과 목록은 없으므로 정답 근거로 추가하지 않았다.
전체 코퍼스에서 여섯 교과명을 모두 포함한 후보를 추가 점검했고,
확인한 두 후보 모두 top20 밖이었다.

질문이 길어지고 고시 번호·시행일이 들어가면서 순위가 바뀌었다는 관찰은 가능하지만,
여러 표현을 동시에 변경했으므로 특정 단어가 원인이라고 확정하지 않는다.
질문 문구를 점수에 맞춰 되돌리거나 바꾸지 않았다.

## 개발용 v2 baseline

answerable 11개, unanswerable 2개는 별도 답변 거절 평가 대상으로 유지한다.

| 지표 | Dense body-only |
|---|---:|
| Hit@5 | 0.818 |
| 필수 근거 Coverage@5 | 0.818 |
| 모든 필수 근거 Complete@5 | 0.818 |
| MRR@20 | 0.636 |

9개 질문은 top5에서 필수 근거를 모두 확보한다. 남는 실패는 다음 두 개다.

- q006: 초등 근거 6위, 중등 근거 16위.
- q008: 교과 목록의 두 대체 근거 모두 top20 밖.

이 점수는 기존 v1이나 이전 10개 부분 평가 평균과 직접 비교하지 않는다.
질문 문구·평가 근거·평가 대상이 다르며 검색기 개선 실험이 아니기 때문이다.
이 개발셋에서 여러 번 관찰한 결과이므로 held-out 일반화 성능으로 보고하지 않는다.

## 스냅샷

`eval/snapshots/v2-development-11q-2026-08-27/`에 다음을 함께 고정했다.

현재 작업용 파일명 `questions.v2.draft.jsonl`은 기존 실행 경로 호환성을 위해 유지한다.
고정한 것은 개발 실험용 판본이며, 전문가 독립 검토를 마친 공식 benchmark는 아니다.
문서·모델 캐시는 저장소 원래 위치를 사용하고 파일 hash로 구분한다.
