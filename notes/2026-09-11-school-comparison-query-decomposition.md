# 학교급 비교 질문 분해

## 문제

q006은 초등학교와 중학교 수업 시간을 한 번에 묻는다.

> 초등학교와 중학교 수업 한 시간은 각각 몇 분인가요?

원문 질문 하나로 Dense 검색했을 때 초등학교와 중학교 근거는 각각 6위와 16위였다. 한쪽 근거도
top-5에 들어오지 않아 생성기는 답변을 보류했다. 리랭커로 후보의 순서만 바꾸는 것보다 두 학교급의
근거를 각각 회수하는 검색 계획이 필요한 사례였다.

## 변경

질문에 둘 이상의 학교급이 명시되면 공통 주제를 유지한 채 학교급별 보조 검색문을 만든다.

```text
원문: 초등학교와 중학교 수업 한 시간은 각각 몇 분인가요?
보조 1: 초등학교 교육과정 수업 한 시간 몇 분
보조 2: 중학교 교육과정 수업 한 시간 몇 분
```

각 보조 검색 결과는 해당 학교급 문서로 제한하고 원문 검색 결과와 번갈아 병합한다. 생성 단계에서는
명시된 학교급마다 가장 높은 후보를 하나씩 선택한다. 규칙은 질문에 실제로 등장한 학교급만 사용하며,
정답 수치나 골드 청크 ID를 검색문에 넣지 않는다.

첫 구현에서는 `교육과정`까지 제거해 q009가 학교생활기록부 문단을 선택하는 회귀가 생겼다. 검색
Complete@5만 보면 놓칠 수 있는 문제였다. 생성 회귀 평가에서 발견한 뒤 문서 영역을 나타내는
`교육과정`을 보조 검색문에 보존하고, 생성 출처도 학교급별 순위를 따르도록 수정했다.

## 결과

원문 Dense와 학교급 분해만 비교한 오프라인 ablation 결과다.

| 방식 | Complete@5 | MRR@20 |
|---|---:|---:|
| 원문 Dense | 0.818 | 0.636 |
| 학교급별 검색 후 병합 | **0.909** | **0.803** |

앞서 적용한 범위·내용 검색문 분리와 이번 변경을 함께 사용한 서비스 회귀 결과는 다음과 같다.

| 지표 | 이전 | 현재 |
|---|---:|---:|
| Recall@5 | 0.909 | **1.000** |
| Complete@5 | 0.909 | **1.000** |
| MRR@10 | 0.727 | **0.894** |
| 답변 가능 질문 생성 성공률 | 0.818 | **0.909** |
| 답변 불가 질문 거절률 | 1.000 | **1.000** |

q006은 두 근거가 1·2위에 들어왔고, 생성 답변은 초등학교 40분과 중학교 45분을 각각 인용했다.
q007과 q009도 필요한 근거를 모두 유지했고 생성에 성공했다. 남은 답변 가능 실패 q011은 검색이
아니라 표의 기간 단위를 해석하는 생성 단계 문제다.

## 한계

- 같은 11개 답변 가능 개발 질문에서 규칙을 만들고 평가했다.
- 학교급 비교 질문은 3개뿐이며, 고등학교를 포함한 3자 비교는 별도 검증이 필요하다.
- 학교급 표현을 규칙으로 찾으므로 생략된 대상이나 우회 표현은 처리하지 못한다.
- 생성 지연은 로컬 머신 부하와 모델 warm-up 영향을 크게 받아 단일 실행끼리 비교하지 않았다.
- 인용 평가는 원문 문자열 존재 여부만 검사하며 답변의 의미적 정확성을 자동 평가하지 않는다.

이 결과는 탐색용 개발 실험이다. 확장 골드셋을 검수하고 미사용 질문에서 다시 측정해야 일반화 성능으로
보고할 수 있다.
