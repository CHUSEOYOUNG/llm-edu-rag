# 질문 구조별 실패 분석

## 연구 질문

교육 규정 QA에서 근거의 배치와 요구 연산에 따라 검색·생성 실패 양상이 달라지는가?

현재 13문항에 `family`, `evidence_layout`, `operations`를 라벨링하고
`experiments/regression_generation_scope_query.json`의 검색·생성 결과를 유형별로 다시 집계했다.
분류표는 `assistant_reviewed_draft_not_expert_validated`이며 정답 내용을 모델 입력에 추가하지 않는다.

## 근거 배치별 결과

| 근거 배치 | 문항 수 | Complete@5 | MRR@10 | 생성 성공률 | 실패 |
|---|---:|---:|---:|---:|---|
| 단일 문단 | 7 | **1.000** | 0.833 | 0.857 | q011 |
| 다중 문단 | 4 | 0.750 | 0.542 | 0.750 | q006 |
| 코퍼스에 답 없음 | 2 | - | - | 거절률 1.000 | 없음 |

현재 개발셋에서는 다중 문단 질문의 검색과 생성 성공률이 단일 문단 질문보다 낮다.
다만 각 그룹이 4개와 7개뿐이라 일반적인 성능 차이로 확정할 수 없다.

## 질문 계열별 관찰

| 질문 계열 | 문항 수 | Complete@5 | 생성 성공률 | 해석 |
|---|---:|---:|---:|---|
| 조건·예외 | 2 | 1.000 | 1.000 | 원칙과 예외가 같은 문단에 있을 때는 성공 |
| 학교급 비교 | 3 | 0.667 | 0.667 | q006에서 초·중 근거를 함께 확보하지 못함 |
| 표 조회 | 2 | **1.000** | **0.500** | 검색은 성공했지만 q011 기간 단위 해석 실패 |
| 시행 범위+내용 | 1 | 1.000 | 1.000 | q008 쿼리 분리 후 성공 |
| 답변 불가 | 2 | - | 거절률 1.000 | 두 질문 모두 답변을 만들지 않음 |

표 질문은 검색 Complete@5가 1.0인데 생성 성공률은 0.5였다. q011에서 모델이 2년 기준 표 값을
연간 값으로 표현했고 검증기가 이를 차단했다. 이 사례는 검색 지표 상승만으로 최종 답변 품질을
설명할 수 없으며 검색과 생성을 별도 층으로 평가해야 한다는 근거다.

q006은 다중 근거이면서 학교급 비교 질문이다. 초등학교와 중학교 문단 중 일부만 top-5에 들어오므로
생성 전에 보류된다. 다음 실험은 학교급별 보조 검색문을 각각 만들고 두 후보군을 합치는 방식이다.

## 재현

```sh
.venv/bin/python eval/analyze_failure_types.py
```

- 분류표: `eval/question_taxonomy.v1.json`
- 집계 결과: `experiments/failure_type_breakdown.json`
- 입력 회귀 결과: `experiments/regression_generation_scope_query.json`

## 한계

- 실패 사례를 본 뒤 분류 축을 정한 개발 분석이다.
- 유형별 문항 수가 1~7개로 작다.
- `operations`는 중복 라벨이므로 유형별 표본 수를 합산하면 안 된다.
- 인용 유효성은 원문 위치와 문자열을 검사하며 의미적 함의를 자동 판정하지 않는다.
- 후속 질문 유형은 현재 13문항 회귀셋에 없으므로 확장 골드셋에서 추가해야 한다.

따라서 현재 결과는 가설을 만드는 탐색 분석으로 보고한다. 30~50문항 검수와 별도 미사용 질문 평가를
마친 뒤에만 유형 간 차이를 일반 성능으로 해석한다.
