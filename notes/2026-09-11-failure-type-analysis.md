# 질문 구조별 실패 분석

## 연구 질문

교육 규정 QA에서 근거의 배치와 요구 연산에 따라 검색·생성 실패 양상이 달라지는가?

현재 13문항에 `family`, `evidence_layout`, `operations`를 라벨링하고
`experiments/regression_generation_table_context.json`의 검색·생성 결과를 유형별로 다시 집계했다.
분류표는 `assistant_reviewed_draft_not_expert_validated`이며 정답 내용을 모델 입력에 추가하지 않는다.

## 근거 배치별 결과

| 근거 배치 | 문항 수 | Complete@5 | MRR@10 | 생성 성공률 | 실패 |
|---|---:|---:|---:|---:|---|
| 단일 문단 | 7 | **1.000** | 0.833 | **1.000** | 없음 |
| 다중 문단 | 4 | **1.000** | **1.000** | **1.000** | 없음 |

학교급 비교 질문을 분해하기 전에는 다중 문단 그룹의 Complete@5와 생성 성공률이 모두 0.750이었다.
분해 후 q006을 회복하면서 두 값이 1.000이 됐다. 표본이 4개뿐이므로 다중 문단 질문이 일반적으로
해결됐다고 해석하지 않고, 현재 개발 사례에서 관찰한 변화로만 기록한다.

## 질문 계열별 관찰

| 질문 계열 | 문항 수 | Complete@5 | 생성 성공률 | 해석 |
|---|---:|---:|---:|---|
| 조건·예외 | 2 | 1.000 | 1.000 | 원칙과 예외가 같은 문단에 있을 때 성공 |
| 학교급 비교 | 3 | **1.000** | **1.000** | 급별 보조 검색으로 필요한 학교급 근거를 함께 확보 |
| 표 조회 | 2 | **1.000** | **1.000** | 질문 기반 표 구조화 후 q011 회복 |
| 시행 범위+내용 | 1 | 1.000 | 1.000 | q008 검색문 분리 후 성공 |
| 답변 불가 | 2 | - | 거절률 1.000 | 두 질문 모두 답변을 만들지 않음 |

표 구조화 전에는 표 질문의 검색 Complete@5가 1.0인데 생성 성공률은 0.5였다. q011에서 모델이
2년 기준 값을 연간 값으로 표현했기 때문이다. 질문에 나온 표의 행·학년 열·값·기간을 구조화하고
표 셀과 기간 주석을 함께 인용하게 한 뒤 q011이 통과했다. 검색 결과는 바뀌지 않았으므로 이 변화는
생성 입력과 검증 단계의 개선이다.

q006은 다중 근거이면서 학교급 비교 질문이다. 분해 전에는 초등학교와 중학교 근거를 top-5에 함께
모으지 못했지만, 학교급별 보조 검색과 후보 병합 후 두 근거가 1·2위에 들어왔다. 생성기도 두 학교급
원문을 각각 받아 40분과 45분을 함께 답했다.

## 재현

```sh
.venv/bin/python eval/analyze_failure_types.py
```

- 분류표: `eval/question_taxonomy.v1.json`
- 집계 결과: `experiments/failure_type_breakdown.json`
- 입력 회귀 결과: `experiments/regression_generation_table_context.json`

## 한계

- 실패 사례를 본 뒤 분류 축을 정한 개발 분석이다.
- 유형별 문항 수가 1~7개로 작다.
- `operations`는 중복 라벨이므로 유형별 표본 수를 합산하면 안 된다.
- 인용 유효성은 원문 위치와 문자열을 검사하며 의미적 함의를 자동 판정하지 않는다.
- 후속 질문 유형은 현재 13문항 회귀셋에 없으므로 확장 골드셋에서 추가해야 한다.

따라서 현재 결과는 가설을 만드는 탐색 분석으로 보고한다. 30~50문항 검수와 별도 미사용 질문 평가를
마친 뒤에만 유형 간 차이를 일반 성능으로 해석한다.
