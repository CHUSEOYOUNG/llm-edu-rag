# 로컬 생성 회귀 평가

## 목적

검색 결과가 좋아져도 생성 답변이 안전하다는 보장은 없다. 13문항을 한 번에 실행해 검색 근거 회수와 생성 응답 상태를 분리해 기록하고, 코드 변경 전후의 실패 유형을 비교했다.

## 실행

```sh
./.venv/bin/python eval/run_eval.py --generate \
  --output experiments/regression_generation.json \
  --baseline experiments/regression_generation_baseline.json
```

평가기는 Ollama의 모델 목록만 확인하지 않고 `qwen3:4b-instruct`를 실제로 한 번 불러온다. 모델 서버가 꺼져 있거나 메모리 부족으로 모델을 적재하지 못하면 Dense 검색기를 준비하기 전에 중단한다.

## 변경 내용

- `insufficient_evidence`는 빈 근거 목록만 허용하도록 구조화 출력과 파서를 맞췄다.
- 비교 질문은 초등학교와 중학교처럼 서로 다른 범위를 지원하는 자료를 함께 선택한다.
- 학교급은 본문의 우연한 단어보다 문서 유형과 항목 경로에 표시된 범위를 우선한다.
- 표의 특정 행과 열이 질문과 관련되면 표가 속한 항목을 생성 문맥으로 확장한다.
- 선택한 자료 전체에서 질문의 학교급·연도 조건을 확인하지 못하면 생성 호출 전에 보류한다.
- 비교 답변은 비교 대상별 자료를 실제 답변 근거로 인용해야 한다.
- 다년간 합계가 적힌 표의 값을 연간 값으로 표현하면 검증 단계에서 차단한다.

검색 지표는 `Recall@5 0.8182`, `Complete@5 0.8182`, `MRR@10 0.6364`로 변하지 않았다.

## 답변 수동 검토

자동 성공률은 응답 상태와 원문 인용 위치만 측정한다. 답변과 인용 사이의 의미적 함의는 측정하지 않기 때문에 생성 문장을 별도로 읽었다.

- q001~q005, q007, q009, q010은 기대한 핵심 내용을 답했다.
- q006은 중학교 시간 근거가 검색되지 않아 보류했다.
- q008은 정답 근거가 상위 10개에 없어 보류했다. 변경 전에는 잘못된 과목을 답했지만 인용 형식만 통과했었다.
- q011은 2년간 408시간을 연간 408시간으로 표현한 실행이 있어 검증 단계에서 차단했다.
- q012와 q013은 코퍼스에 없는 질문으로 올바르게 보류했다.

따라서 이번 결과는 생성 기능의 최종 정확도가 아니다. 현재 남은 핵심 문제는 q006·q008의 검색 근거 회수와 q011 같은 표 의미 검증이다. CrossEncoder는 앞선 실험에서 질문당 평균 12.8초가 걸렸으므로 바로 서비스에 넣지 않고, 다음에는 가벼운 후보 확장과 parent-child 문맥 구성을 먼저 비교한다.
