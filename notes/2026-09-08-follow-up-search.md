# 직전 질문을 잇는 검색

## 목적

검색 화면에서 첫 질문의 조건을 반복해서 적지 않아도 되도록 한 단계의 후속 질문을 지원한다.

```text
첫 질문: 초등학교 수업 한 시간은 몇 분인가요?
후속 질문: 그럼 중학교는?
실제 검색문: 중학교 수업 한 시간은 몇 분인가요
```

## 동작 범위

- `그럼`, `그러면`, `그렇다면`, `그건`, `그때`, `그 경우`, `그중`처럼 앞 질문을 가리키는 표현을 확인한다.
- `중학교는?`, `고등학교도?`처럼 학교급만 바꿔 묻는 짧은 질문도 후속 질문으로 본다.
- 완결된 새 질문은 직전 질문과 합치지 않는다.
- 브라우저가 직전의 실제 검색문 하나만 요청에 포함한다. 서버는 사용자별 대화 기록을 저장하지 않는다.
- 합친 검색문이 입력 제한인 4,000자를 넘으면 현재 질문만 검색한다.

## 응답 확인

API는 사용자가 입력한 문장을 `context.original_question`에 그대로 보존한다. 검색기에 전달한 문장은 `search_query`, 후속 질문 적용 여부는 `follow_up_applied`로 반환한다. 화면에도 후속 질문을 어떤 문장으로 해석했는지 표시한다.

이 기능은 규칙 기반의 한 단계 문맥 보충이다. 대명사가 가리키는 대상이나 여러 차례의 긴 대화까지 의미적으로 해석한다고 보장하지 않는다.
