# 표의 기간 정보를 생성기에 전달하기

## 확인한 문제

q011의 질문은 `초등학교 3~4학년 국어 수업 시수는 몇 시간인가요?`다. 검색기는 정답 청크를
1위로 찾았지만 생성 결과는 검증 단계에서 막혔다.

원문 표에서 확인한 값은 다음과 같다.

```text
행: 국어
열: 3~4학년
값: 408시간
기간: 연간 34주를 기준으로 2년간
```

PDF에서 병합 셀을 Markdown으로 옮기는 과정에서 첫 번째 열이
`|국어<br>국어 482|408|408|`처럼 무너졌다. 값과 기간 주석은 원문에 남아 있었지만 Qwen3 4B가
408시간을 연간 값으로 표현했다. 기존 검증기는 이 답을 화면에 내보내지 않은 점에서는 제대로
동작했지만, 올바른 답을 만드는 데 필요한 표 구조는 모델에 제공하지 못했다.

## 변경한 방식

질문에 학년 범위와 수치 단위가 명시된 경우에만 검색 문단의 Markdown 표를 좁게 읽는다.

1. 질문에서 `3~4학년`, `국어`, `시간`을 찾는다.
2. 표 머리글에서 `3~4학년` 열을 찾는다.
3. 질문의 과목명이 들어 있는 행을 찾는다.
4. 행과 열이 만나는 값 `408`을 읽는다.
5. 같은 문단에서 `연간 34주 기준`, `2년간` 주석을 찾는다.

이 결과를 `table_facts`로 만들어 원문 passages와 함께 모델에 전달한다.

```json
{
  "row_label": "국어",
  "column_label": "3~4학년",
  "value": "408",
  "unit": "시간",
  "period": "2년간",
  "basis": "연간 34주 기준"
}
```

모델이 행·열·값·기간을 모두 맞게 답했을 때만 프로그램이 표 셀과 기간 주석의 원문 인용을 붙인다.
값만 맞고 학년이나 기간이 빠지면 검증에 실패한다. 구조화 결과가 없는 일반 질문은 기존 생성 경로를
그대로 사용한다.

## 중간에 실패한 시도

프롬프트에 기간을 정확히 쓰라고 지시했을 때 q011 답 문장은 맞아졌다. 하지만 모델이 408이 적힌
표만 인용하고 `2년간`이 적힌 주석은 인용하지 않아 강화한 검증을 통과하지 못했다.

두 번째 수정에서는 답 문장이 구조화한 사실과 전부 일치할 때 표 셀과 기간 주석의 passage를
프로그램이 확정했다. 모델이 근거 번호를 고르는 실수 때문에 맞는 답을 버리지 않으면서, 다른 값을
말한 답에는 자동으로 근거를 붙이지 않도록 제한했다.

생성 문장에 `S1-P2` 같은 내부 번호가 노출되는 경우도 있어, 내부 번호가 들어간 부가 문장은 화면에
표시하기 전에 제거하고 검증 단계에서도 차단했다.

q011의 최종 답변은 다음과 같다.

> 초등학교 3~4학년 국어 수업 시수는 2년간 408시간입니다. 이는 연간 34주를 기준으로 한 기준 수업 시수입니다.

13문항 전체 회귀에서 답변 가능한 11문항은 모두 답변과 출처 검사를 통과했고, 답변이 없는 2문항은
계속 보류했다. 생성 문장은 직접 읽어 확인했지만 교육 정책 전문가 검토는 하지 않았다.

## 한계

- 질문에 학년 범위와 과목명이 명시된 표 조회만 구조화한다.
- 표 전체의 병합 셀을 복원한 것이 아니라 질문에 필요한 한 셀만 연결한다.
- 같은 개발 질문으로 문제를 찾고 수정했으므로 미사용 질문에서 다시 평가해야 한다.
- 현재 인용 검사는 원문 문자열과 기간 존재를 확인하며 답변 전체의 의미적 함의를 판정하지 않는다.
- 회귀셋이 13문항으로 작아 성공률 1.0을 일반 성능으로 해석할 수 없다.
