# 적용 조건과 내용 검색문 분리 실험

## 결론

날짜·고시명이 포함된 내용 질문에만 보조 검색문을 만드는 방식을 서비스에 반영했다.
현재 11개 개발 질문에서는 q008에만 규칙이 적용됐으며, 다른 10개 질문의 순위는 그대로였다.

| 지표 | 원문 Dense | 조건·내용 분리 |
|---|---:|---:|
| Complete@1 | 0.455 | 0.545 |
| Complete@5 | 0.818 (9/11) | **0.909 (10/11)** |
| Complete@10 | 0.818 | **0.909** |
| MRR | 0.636 | **0.727** |

q008의 교과 목록 근거는 원문 질문에서 20위 밖이었고 보조 검색문에서는 1위였다.
서비스 검색 회귀에서도 q008의 R@1·R@5·R@10은 모두 1.0이었다.

## 원인

q008은 하나의 질문이지만 필요한 정보는 두 위치에 나뉜다.

- `s003::다::0`: 2028년 3월 1일과 초등학교 1·2학년 적용 범위가 `path`에 있음
- `s019::1::0`: 실제 교과 목록이 `body`에 있음

body-only Dense에 원문 전체를 넣으면 고시명·날짜·적용 표현이 강하게 작용해 고시 서두가 상위에 왔다.
학교급 필터는 원인이 아니었다. 필터 전 목록 근거는 40위, 초등학교 필터 후에는 18위였다.

## 구현

원문 질문은 답변과 범위 검증의 기준으로 계속 보존한다. 날짜나 고시명이 있고 내용을 묻는 질문에만
법적·시간적 수식어를 뺀 보조 검색문을 추가한다. q008의 실제 보조 검색문은 다음과 같다.

```text
초등학교 1·2학년에 교과는 무엇인가요?
```

보조 검색 결과와 원문 검색 결과를 보조 검색 우선 round-robin으로 합친다.
명시된 날짜를 포함한 문단이 최종 결과에 없으면 후보군에서 날짜 문단을 하나 보충한다.
생성기에는 첫 내용 문단과 날짜 범위 문단을 함께 넘긴다.

문서의 `1, 2학년`과 질문의 `1·2학년`은 학년 범위 구분기호 차이로만 취급하도록 범위 검증도 보완했다.

## 생성 회귀

Ollama `qwen3:4b-instruct`로 13문항을 다시 실행했다.

| 지표 | 변경 전 | 변경 후 |
|---|---:|---:|
| 전체 상태 성공률 | 0.769 | **0.846** |
| 답변 가능 질문 성공률 | 0.727 | **0.818** |
| 인용 형식 유효율 | 0.727 | **0.818** |
| 답변 불가 질문 거절률 | **1.000** | **1.000** |

q008은 국어, 수학, 바른 생활, 슬기로운 생활, 건강한 생활, 즐거운 생활을 답했고 원문 인용 검증을 통과했다.
q006은 두 학교급 근거가 top-5에 함께 없어서 계속 답변을 보류한다. q011은 2년 기준 값을 연간 값으로
표현한 모델 출력을 검증기가 차단했다.

## 리랭커와의 비교

기존 `bge-reranker-v2-m3` 실험은 MRR을 0.636에서 0.700으로 높였지만 Complete@5는 0.818로 같았다.
q002·q006은 개선하고 q004는 악화했으며, CPU 지연이 질문당 평균 12.8초였다. q008 근거는 Dense top-20에
없어서 리랭커가 볼 수도 없었다. 이번 방식은 q008의 1차 후보 회수를 직접 고치며 실제 검색 추가 시간은
회귀 실행에서 약 0.27초였다.

## 한계

같은 11개 개발 질문으로 원인을 분석하고 규칙을 선택했다. 독립 테스트 성능이 아니며, 날짜·고시명이 있는
새 질문에서 같은 효과가 나는지 추가 검증이 필요하다. 인용 검사는 원문 문자열의 출처를 확인할 뿐 답변의
의미 전체가 근거에서 함의되는지는 자동 판정하지 않는다.

재현 결과는 `experiments/ablation_scope_query.json`과
`experiments/regression_generation_scope_query.json`에 저장했다.
