# 골드셋 확장 검수 큐

현재 검색·생성 회귀셋은 13문항이라 한 문항이 답변 가능 검색 지표의 약 9%p를 바꾼다.
기존 answerability 벤치마크 32문항에서 현재 질문과 문장이 완전히 같은 항목을 제외해
26개 검수 후보를 `eval/gold_expansion_review.jsonl`에 준비했다.

| 후보 유형 | 개수 | 용도 |
|---|---:|---|
| 새 근거 문단 질문 | 5 | 출결·학생정보 등 검색 범위 확장 |
| 기존 근거의 다른 표현 | 7 | 구어체·표현 변화 견고성 확인 |
| 답변 불가 질문 | 14 | 환각·과잉 답변 방지 확인 |
| 합계 | 26 | 기존 13개와 합치면 최대 39개 |

이 파일은 점수에 바로 넣는 골드셋이 아니다. 모든 항목은 `pending_human_review`이며 다음 검수가 필요하다.

1. 실제 사용자가 물을 법한 질문인지 확인한다.
2. 답변 가능 질문은 원문을 읽고 reference answer를 작성한다.
3. 답에 필요한 사실을 evidence group으로 나누고 정확한 문단을 지정한다.
4. 학교급·학년·시행일·기간 조건을 확인한다.
5. 답변 불가 질문은 고정 코퍼스 전체에 사실이 없는지 확인한다.

기존 `development`·`test` 표시는 후보의 출처 기록일 뿐 새 독립 테스트셋 지위를 뜻하지 않는다.
이미 개발 과정에서 본 질문이므로 승인 후에도 개발/회귀셋으로 쓰고, 최종 성능은 별도로 수집한 질문에서
한 번 측정해야 한다.

검수 큐 재생성:

```sh
.venv/bin/python eval/build_gold_review_queue.py
```
