# 선생님·학생·학부모를 위한 화면 개편

## 변경 방향

개발자용 검색 실험 화면을 교육 정보 서비스 형태의 **학교생활 안내**로 바꿨다. 밝은 파란색, 학교 그림, 큰 글자와 여백, 생활 속 질문을 중심으로 구성했다. 휴대폰에서는 장식 그림을 숨기고 질문·자료 읽기에 집중하도록 했다.

검색 알고리즘과 평가셋은 바꾸지 않았으며, 유료 API와 답변 생성 기능을 추가하지 않았다. 현재는 준비된 교육 자료의 일부를 그대로 보여주는 서비스임을 화면에 명시한다. 공식 기관이 운영하거나 답변의 정확성을 보증하는 것처럼 표현하지 않았다.

## 사용자에게 보이는 변화

| 이전 | 변경 후 |
|---|---|
| 근거 노트 | 학교생활 안내 |
| 근거 찾기 | 찾아보기 |
| 검색 근거 | 이런 내용을 찾았어요 / 관련 자료 |
| 청크 원문 | 자료에서 찾은 내용 |
| 경로·문서명 | 자료 안의 위치·자료 이름 |
| 질문 조건·문구 점검 | 읽으면서 함께 확인해 주세요 |
| 본문 문구 일치 | 내용에서 찾았어요 |
| 문구 없음 | 이 내용에서는 찾지 못했어요 |
| JSON 저장 | 찾은 내용 저장 — 일반 텍스트 파일 |
| 유사도 점수·청크 식별자·모델명 | 사용자 화면에서 제거 |

자료 제목에 붙은 파일 처리용 접미사는 목록에서 숨기고, `(초)`, `(중)`, `(고)`는 학교급 이름으로 표시한다. 출처 확인을 위해 원래 자료 이름과 본문은 상세 정보와 저장 파일에 보존한다. 문서 본문 자체의 용어는 임의로 치환하지 않았다.

## 추천 질문

전체·선생님·학생·학부모를 선택하면 추천 질문 세 개가 달라진다. 예를 들어 선생님에게는 학교생활기록부 글자 수·정정·수업 시간 조정, 학부모에게는 기록 정정·국어 수업·2028년 초등학교 교과 질문을 제시한다.

대상 선택은 추천 질문만 바꾼다. 실제 검색 요청은 화면에 표시된 질문과 검색 개수뿐이며, 숨겨진 필터나 재작성은 적용하지 않는다. 새 UI의 2028년 질문은 사용자용 표현으로 바꾸되 고시 번호·시행일·학교급·학년을 보존했다. 고정 평가셋 질문은 수정하지 않았다.

## 파일과 검증

- `web/index.html`, `web/app.css`, `web/app.js`: 사용자 화면 재구성.
- `web/presentation.js`: 추천 질문, 자료 제목 표시, 쉬운 안내 문구, 텍스트 저장 내용 구성.
- `src/search_app.py`: 새 정적 파일 경로와 사용자용 오류 문구. 검색 순위 계산은 동일.
- Python 테스트 **53개 통과**.
- JavaScript 표시·저장 기능 테스트 **4개 통과**.
- JS 구문 검사 및 HTML 요소 참조·화면 용어 검사 통과.
- 실제 HTTP로 질문 13개를 검색했고, 기준선이 있는 11개는 top-5 순서가 모두 동일했다.
- 모든 실제 검색 응답에서 생성 API 호출 없음·생성 답변 없음 확인.

검증 기록: `experiments/education_ui_check.json`.

내장 브라우저 자동화는 도구 시작 오류가 계속되어 이번 화면의 실제 시각 배치·클릭 검증은 완료하지 못했다. 브라우저에서 실행한 것처럼 보고하거나 화면 캡처를 대신 만들지 않았다. 로컬 서버에 변경 파일을 반영했고, 브라우저에서 새로고침하면 새 화면을 볼 수 있다.

커밋·푸시·외부 배포는 하지 않았다.
