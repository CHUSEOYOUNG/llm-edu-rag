# q009 질문 범위 확정 및 재검색 — 2026-08-27

## 사용자 승인 반영

v2 초안의 q009 질문을 다음과 같이 바꿨다.

> 2022 개정 교육과정 기준으로 초등학교와 중학교의 창의적 체험활동은 어떤 영역으로 구성되나요?

`eval/questions.jsonl`의 v1 질문은 그대로다. v2에는 `original_question`과
`question_revision_status=user_approved`를 남겼고, manifest에는 승인된 변경 전후 문장을 기록했다.
이 승인은 q009 질문 문구에 대한 것이며, 평가셋 전체나 근거 annotation의 최종 승인을 뜻하지 않는다.

수정 전 v2 JSONL/manifest는 `eval/archive/before-q009-scope/`에,
수정 전 평가 결과는 `experiments/evidence_v2_before_q009_revision.json`에 보존했다.

## 동일 근거 규약으로 질문 변경 효과만 비교

Dense body-only, 기존 문서 임베딩 유지, v2 질문 임베딩을 새로 계산했다.
q009 근거 그룹과 답변은 바꾸지 않았다. 기존 질문의 순위와 새 질문의 순위를 각각 저장한다.

| q009 지표 | 기존 질문 + v2 근거 | 수정 질문 + 동일 v2 근거 |
|---|---:|---:|
| Hit@1 | 1.00 | 0.00 |
| Coverage@1 | 0.50 | 0.00 |
| Hit@5 | 1.00 | 1.00 |
| Coverage@5 | 1.00 | 1.00 |
| MRR@20 | 1.00 | 0.50 |
| 모든 필수 근거를 확보하는 순위 | 2 | 2 |

첫 정답 근거 순위는 1위에서 2위로 내려갔다. 새 1위는 총론의 문서 서두
`s000::::1`로, 교육과정 시행 시기와 별책 안내는 있지만 세 영역의 정답은 없다.
새 2위 `고 s077::13조::0`는 초등·중등 근거를 함께 담고 있다.

따라서 질문 범위를 명확히 했지만 상위 1개 결과의 정답 여부는 나빠졌다.
이를 검색기 개선으로 보고하지 않는다. 이 한 질문으로 일반화 성능도 판단하지 않는다.
기존 gold 누락 보정 효과와 질문 수정 효과는 결과 JSON에서 각각
`legacy`, `draft_on_original_query`, `draft`로 분리했다.
